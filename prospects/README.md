# Prospects — handoff queue

Each subfolder is one prospect moving through the pipeline. To add one by
hand, drop a note in `_new-leads.md`; Rupika will turn it into a proper
entry on her next run. To start one programmatically, copy `_template/` to
`<company-slug>/`.

## Stages

`found -> enriched -> drafted -> approved -> sent`

`sent` is set by Kevin, manually (or by explicit instruction on a run),
once a message has actually gone out. No routine sets this stage itself.
